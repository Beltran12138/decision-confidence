这才是重点

「不可比」不是答案，它把一个问题拆回了四个

你想要一个综合分，是因为你把「买不买」当成一个决策。它其实是几个。
构念不匹配就是在告诉你这件事——拆开之后，每一项都指向一个具体动作，和一个当期可触发的证伪条件。

46 分告诉你「中性偏乐观」，你拿它什么也做不了。
拆开之后，四条各自对应一个动作、一个日期、一个能把它打死的条件。
综合分不是信息更多，是把四条可执行的判断压成了一个不可执行的数字。信息在合成那一步就丢了。
那什么才算真分歧

先量一把尺子，再判断谁在吵架

同一个构念内部，两组真实存在的分歧——一组是噪音，一组必须解释。
基准线 · 同问题、同方法
两家数据商，同一个 Forward P/E：
22.60
stockanalysis
08-14
24.28
GuruFocus
08-10
差 7%。它们真的在回答同一个问题，方法也几乎一样（EPS 口径与取数日期略有差别）。
这个 7% 就是你的尺子 —— 「两个源答同一个问题」长这样。
要解释的 · 同一家 vendor 自己打架
GuruFocus 同时给出两个信号：
"Possible Value Trap"警示
GF Value $383.29 vs 市价 $217.09低估 43%
43% ≫ 7%。 远超基准线，所以这条必须解释。
而解释是：这两条不是矛盾，是两个构念。 一个测「便宜不便宜」，一个测「便宜是不是有原因」。
同一家 vendor 同时发出这两条，不是它出错了 —— 是我们习惯把它们读成一条。
没有那把 7% 的尺子，你没法知道 43% 算不算大。
先找一个你确定两个源在读同一个数的指标，量出它的正常差值 —— 那是你判断其他一切分歧的起点。
