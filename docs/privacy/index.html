Privacy

Privacy

No accounts, no cookies, no stored wallet addresses. Last updated 2026-10-15.

The website (evidencedeflator.com)

Static pages hosted on GitHub Pages behind Cloudflare. We count page views with Cloudflare Web Analytics, which sets no cookies and does not identify you. When you check a wallet on the site, your browser asks Hyperliquid’s public API for that wallet’s history directly; the address is not sent to us. After a verdict is shown, the page sends our API one tally that says only “a check was done” and the page language, so we can count daily checks.

The API and MCP server (api.evidencedeflator.com)

When you or your AI assistant call the API or the MCP tool, the request carries a wallet address and, optionally, a number. Our server, a Cloudflare Worker, forwards the address to Hyperliquid’s public info API to fetch that wallet’s history, scores it, and returns the result. We do not store the address or the result, and we have not turned on request logging for the Worker. Each completed check adds one tally to a daily count (whether it came from the API or the MCP tool), without the address or anything about the caller. Cloudflare, which runs the Worker, processes requests (including your IP address) under its own privacy policy. Hyperliquid receives the address under its own terms.

A wallet address on a public blockchain is public data. Do not send anything else; the tool does not need it.

The Telegram bot and the Chrome extension

The Telegram bot receives the messages you send it through Telegram, which processes them under its own privacy policy. The Worker above reads the address in your message, checks it the same way, replies, and keeps nothing: not the message, not your chat or user ID. Each check adds one tally to the daily count.

The Chrome extension reads the address or trader ID in the URL of the page you are on and fetches that record directly from the exchange's public API (Hyperliquid, Binance or OKX). It sends nothing about the trader or you to us; it only downloads our daily board sizes. It has no analytics.

The Python package, Claude Code plugin and skill

They run on your machine. The plugin’s backtest counter keeps a small log of matching shell commands in your local plugin data folder; it is never sent anywhere. The package and plugin contact Hyperliquid (and our API, if you use the hosted MCP tool) only when you check a wallet.

Changes and contact

If this changes, this page and its date change with it, and the history is public in the repository. Questions: GitHub issues.
