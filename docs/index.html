For AI backtests · where the method started

Three numbers, before any performance figure

Each is plain arithmetic on inputs a project can state in one line. None needs the strategy’s code. Check a backtest →

Read the method →
01 · OPEN-BOOK MONTHS

What the model may have seen

Months of the test window on or before the model’s training cutoff. For those months, we cannot rule out that it already knows what happened.

02 · CLEAN MONTHS NEEDED

How long the result must run

A Sharpe of 1 needs about 48 clean months to reach t = 2; a Sharpe of 2 needs 12. The quadratic is the whole story.

03 · BAR AFTER SELECTION

How many tries it beat

The best of N attempts must clear a higher bar. Best of 41: t ≥ 3.26. Best of 23,376: t ≥ 4.76.

Worked example

A 2020–2025 backtest, model cutoff 2024-10

66 months in the window. 58 cannot be ruled out as seen. 8 are clean, against the 48 a Sharpe-1 claim needs. Verdict: underpowered — it rejects nothing, and it shows nothing.

Use it

Pure Python, no keys, no network

The engine is the standard library. Fetching data is your job; the value is a repeatable, comparable answer.

API reference →
from evidence_deflator import effective_window

w = effective_window(cutoff="2024-10", start="2020-01",
                     end="2025-06", trials=41)
print(w.open_book_months, w.effective_months, w.months_required, w.verdict)
# 58 8 128 underpowered
# from a clone of the repository
python tools/window.py --cutoff 2024-10 --start 2020-01 --end 2025-06
# 66 months, 58 cannot be ruled out as seen, 8 clean; Sharpe 1 needs ~48
