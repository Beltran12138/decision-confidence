# 预注册 · 回溯冻结检验（2026-10-15，写于任何计算之前）

问题：在榜单上挑出来的钱包里，我们的 t 能不能比「按利润排名」更好地预测之后的表现？

## 数据
- 冻结点：Wayback 存档的 Hyperliquid 排行榜快照 2025-11-10、2026-01-26、2026-04-03（各取当日第一个 200 快照）。
- 名单规则与 10-14 冻结队列相同：当日全期 PnL 前 100 + 30 日 ROI 前 100（账户 ≥ $10k），去重。
- 冻结前记录：今天拉的 portfolio 截断到冻结时刻，`weekly_returns` + `score` → t_before。
- 冻结后记录：`weekly_returns(pf, since=冻结时刻)` + `score` → t_after（至少 8 周，否则不计）。

## 主检验（每个冻结点分别算，再报三点合并）
- ρ_t = Spearman(t_before, t_after)
- ρ_pnl = Spearman(冻结时全期 PnL, t_after)
- **算我们赢**：三个冻结点里至少两个 ρ_t > ρ_pnl，且合并样本 ρ_t 的 95% bootstrap 区间不含 0。
- **算我们输**：合并 ρ_t ≤ 0，或三个点里 ρ_t > ρ_pnl 少于两个。
- 其余＝不确定，照实报。

## 次检验（只报告，不定输赢）
- t_before ≥ 2 那组与 < 2 那组的 t_after 中位数之差。
- t_after ≥ 2 的比例（随机基线约 2.3%）。

## 不做的事
- 不换冻结点、不换名单规则、不换窗口来「找」一个赢的结果；结果不论输赢都写进审计页和 YC 申请。
